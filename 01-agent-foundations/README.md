# Module 1 — Agent foundations (Sessions 1–3)

Build an AI agent from scratch, with no framework, so that every framework later in the
course maps back to code you have already written yourself.

| Notebook | Session | What it covers |
|---|---|---|
| `01_agent_from_scratch.ipynb` | 1–2 | The wall an LLM hits, tools as JSON schemas, and the agent loop in ~40 lines. **Project: a research agent with search, calculator and memory.** |
| `02_agentic_patterns_and_context.ipynb` | 3 | The five agentic patterns, the autonomy ladder, and context engineering |
| `03_measuring_agents.ipynb` | 3 | Outcome vs trajectory evaluation, LLM-as-a-judge, and judge bias. **Project: an evaluation harness you reuse all course.** |
