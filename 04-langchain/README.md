# Module 4 — LangChain (Sessions 8–10)

Provider-independent building blocks, agents assembled from them, and retrieval that an
agent decides to use.

| Notebook | Session | What it covers |
|---|---|---|
| `01_langchain_components.ipynb` | 8 | Models, prompts, structured output, LCEL. **Project: a review-intelligence pipeline over 36 customer reviews — deliberately with no agent.** |
| `02_agents_create_agent.ipynb` | 9 | `create_agent` and middleware: call limits, PII redaction, human approval, tool errors. **Project: a data-analyst agent that investigates a ratings drop.** |
| `03_agentic_rag_mcp.ipynb` | 10 | Documents, read-only SQL and web search as tools; connecting MCP servers. **Project: an incident investigator.** |
